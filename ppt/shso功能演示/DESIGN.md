# DESIGN.md — shso 功能演示 PPT

> 视觉方向：暗色科技风（深空底 + Aurora 青 + 橘红强调），贴合 App 自研 UI 主题 `AuroraTokens`。
> 受众：普通用户 / 推广向。措辞突出「能做什么、好用在哪里」，弱化实现细节。

## 1. 画布与全局母版

- 画布：1280 × 720（16:9），固定。
- 安全区 padding：上下 20px、左右 72px。
- 默认三区（内容页严格复用）：
  - A 标题块：0–120px，主标题 34px bold（左对齐，距左 72px）。
  - B 内容区：120–660px，540px 可用。
  - C 页脚条：660–720px，左侧「shso · 功能演示」14px 灰字，右侧页码 `NN / 28` 14px。
- 封面 / 章节扉页 / 结束页：自定义版式（可省略 C 区或放大主视觉）。

## 2. 颜色系统（暗色科技）

色彩池（计入「色彩池」的彩色仅 3 个 hex，中性灰阶不计入）：

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色 青 | `#22D3EE` | 标题强调、图标、主视觉线条、页码高亮 |
| 辅色 天蓝 | `#7DD3FC` | 渐变收尾、次级图标、分隔线 |
| 强调 橘红 | `#FF5722` | 关键数据、CTA、焦点标注（与 App `AccentOrange` 一致） |
| 背景 深空 | `#0B1220` | 页面底色 |
| 面板 | `#15203A` | 卡片 / 区块底色 |
| 文本 | `#E2E8F0` | 正文主色 |
| 次文本 | `#94A3B8` | 说明 / 脚注 |
| 边框 | `#334155` | 卡片描边、分隔线 |

**面积分配**：主色/背景合计 ≤ 60%（深空底占大头）；辅色 ≤ 30%（面板、渐变）；强调色 ≤ 10%（仅焦点）。Hero 页强调色可升至 15–20%。
**渐变**：`linear-gradient(135deg, #22D3EE 0%, #7DD3FC 100%)`（标题条 / 主视觉光带）；背景叠加 `radial-gradient` 青色微光（opacity 0.08–0.15）；暗化蒙版 `rgba(0,0,0,0.4)` 用于全幅底图压字。
**半透明**：卡片 `background: rgba(21,32,58,0.9)`，浮起 `boxShadow: 0 8px 30px rgba(0,0,0,0.35)`。

## 4. 信息密度

- 常规内容页留白 ≤ 35%，每页至少 1 个视觉锚点（≥ 44px 元素或 ≥ 40% B 区图形）。
- 内容页正文下限约 150–220 字；卡片每组 ≥ 3 张时每卡 ≥ 90 字。
- 封面 / 章节 / 结束页允许 35–50% 留白，但须围绕核心元素。

## 5. 配图系统

- 本 deck 全篇采用 **SVG 抽象科技视觉**（深空渐变 + 网格 + 青色光晕 + 电路/几何母题），属「背景网格 / 抽象几何概念页」范畴，按规范用 `<SVG>`，不依赖 ImageGen、不用真实截图。
- L1 主视觉（封面 / 章节 / 结束）：满幅 SVG 背景（网格 + 径向光晕 + 巨型章节序号）。
- L2 支撑图：功能页的 SVG 架构/流程/对比图（≥ 280×180）。
- L3 母版徽标：页脚左侧青色 `shso` 文字标记，全篇位置一致。
- 图标一律用 `FAIcon`（实心、统一 32–48px、青/橘红着色），禁止 Emoji。
- 配图清单：见「页面映射表」L1 列；均为 SVG，本地内联，无需 assets 文件。
