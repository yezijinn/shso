## 📖 项目简介

**shso** 是一款运行在 Android ROOT 环境下的图形化辅助执行工具（包名 `com.mixradio.droid`，版本 9.0.2/283）。

在日常玩机、系统调优或模块调试过程中，经常需要运行 Shell 脚本（`.sh`）或原生可执行程序（`.so` / ELF 二进制）。shso 把这一流程图形化：无需面对复杂命令行即可一键执行脚本、实时查看带 ANSI 颜色高亮的控制台日志、进行标准输入交互，并在手机上完成全盘 ROOT 级别的文件管理、文本编辑/对比、压缩包解压与 APK 安装。界面为等宽字体 + 直角矩形玻璃暗色风格，冷启动直接进入主页四 Tab（主页 / 终端 / 文件 / 设置），无多余加载流程。

> **权限模型（核心原则）**：普通用户本就能用的功能（浏览文件列表、删除 / 拷贝 / 重命名、文本编辑、解压、安装 APK、书签等）**不强制依赖 ROOT**；仅当设备授权 ROOT 时，**优先使用 ROOT 权限**（可覆盖受保护 / 系统路径），其余情况回退普通文件权限（`java.io.File`）。`/data/adb/shso` 工作区写入属天然 ROOT 专属路径。

## 1. 🚀 主页（Home）

- **路径执行**：直接输入文件绝对路径，或点击「从文件管理器选择」调起内置选择器。
- **格式限制**：仅允许执行 `.sh` 脚本与 `.so` 二进制程序，其余格式明确拒绝并提示。
- **立即执行**：校验通过后调用执行引擎，自动跳转终端页展示实时日志；任务运行中可「点击覆盖启动」。
- **shso 目录文件**：内置展示 `/data/adb/shso` 工作区文件（图标区分 文件夹 / SH / SO / 普通文件），点击选中、按钮「选择」，支持上级返回与刷新；字号跟随全局文件列表设置。

## 2. 💻 终端（Terminal）

- **ANSI 文本着色**：内置 ANSI 转义序列解析器，支持标准 16 色与加粗渲染；文字颜色可在终端设置中通过色轮自定义（彩虹色相条 + 明暗条 + 16 个预设色）。
- **中文状态灯**：左上角状态点 + 文字——空闲为绿「待命中」，运行中为红「运行中」并带循环点（`.` `..` `...` `....` `.....` 每 400ms 递增）。
- **紧凑操作区**：顶部一排裸文字按钮——`复制输出` / `结束进程`（运行中才可点）/ `重启终端` / `设置`。
- **输入与交互**：底部「请输入命令…」输入行 + `中断`（SIGINT）/ `清屏` / `Enter`（发送空行）/ `发送`（发送 stdin）。
- **终端设置随页而至**：文字颜色（色轮）、终端字体大小（5–30sp 滑杆）、`HyperCore 终端提示` 开关、`shso 终端提示` 开关。
- **智能滚动**：仅在用户已停在底部时自动跟随新日志，向上回看时不被拽回。
- **输出上限保护**：滑动窗口截断（上限 25 万字符），防止超长日志 OOM。

## 3. 📁 文件管理（File）

### 3.1 浏览与导航
- **默认工作区**：内置快捷直达 `/data/adb/shso`（历史遗留的 `/data/adb/KernelEX` 不迁移、不删除）。
- **全盘访问**：浏览系统根目录 `/`、内部存储、受保护 `/data` 分区（ROOT 时）。
- **顶栏六等分**：`返回 | data | storage | shso | ⭐书签 | 设置`。
- **记忆操作路径**：开关（默认开）记忆上次浏览目录，关闭则恒回 `/storage/emulated/0`。

### 3.2 列表设置（文件列表设置弹窗）
- **排序**：名称升序 / 名称降序 / 时间升序 / 时间降序。
- **隐藏文件**：开关显示以 `.` 开头的隐藏条目。
- **字体大小**：5–30sp 调节（默认 15sp），与主页 shso 目录列表共用。

### 3.3 单文件动作（长按文件弹菜单）
- `添加到shso`、`安装 APK/XAPK`（可安装时）、`浏览图片`（图片文件）、`编辑文本`（文本文件）、`重命名`、`拷贝`、`删除`。
- **重命名 / 拷贝** 自动过滤 `..` `\` `\0` 等非法字符；拷贝生成同级 `_n` 递增副本。

### 3.4 多选批量
- 长按非文件夹文件 → 「进入多选模式」；多选模式下**单击切换选中**（仅文件，文件夹不参与）。
- 已选中后长按 → 「退出多选模式」或「批量操作（已选 N 项）」菜单。
- 批量操作：对全部选中项 **删除 / 拷贝（`_n` 副本）/ 重命名（统一名称 + `_n` 保留原扩展名）**，完成后自动退出多选。

### 3.5 三悬浮导航按钮
- 列表右下悬浮 `⤒`（回到顶部）/ `⤓`（直达底部）/ `⟳`（刷新列表），靠右距 50dp、位于可能的「执行」按钮左侧，样式为极光渐变透明图标。
- 布局铁律（已锁定，不再改动）：列表外层 `Box` 仅预留 DockBar 高度（`weight(1f).fillMaxWidth().padding(bottom = 56.dp)`），列表底端恰好止于底部导航上沿，透明导航栏下方只显示极光背景、不穿透文件列表。

### 3.6 APK / XAPK 安装
- **ROOT 已授权**：静默安装——单 APK 先 `cp` 到 `/data/local/tmp` 再 `pm install -r -d -t`；XAPK / split 分片走 `pm install-create/write/commit` 会话流，OBB 落位 `/sdcard/Android/obb/<包名>/`。
- **无 ROOT**：回退系统安装器（FileProvider + `ACTION_VIEW`），由用户交互完成；受保护路径（如 `/data/adb`）非 ROOT 不可读时给出明确提示。
- 兼容伪装名（如 `qq.apk.1`、大小写变体）。

### 3.7 图片浏览
- 点击图片文件（jpg/jpeg/png/bmp/gif/webp/ico/tiff/tif）→ 全屏查看器：右下角 `←` 上一张 / `→` 下一张 / `↻` 顺时针旋转 90°；支持双指缩放与拖动平移。

### 3.8 字体预览与应用
- 点击 `.ttf` / `.otf` 字体文件 → 预览对话框，可「应用为软件字体」设为全局等宽字体（自定义字体设置持久化）。

### 3.9 新建文件（设置菜单子项）
- **入口**：文件页右上角「设置」齿轮 → 菜单底部纯文本子项「新建文件」（Accent 色，无矩形底色，符合弹窗紧凑风格）。
- **对话框**：点击弹出「新建文件」对话框，两个并排输入框——
  - 左「文件名」：预填**今天日期到毫秒的纯数字**（如 `20260905200050166`，17 位 `yyyyMMddHHmmssSSS`）；
  - 右「扩展名」：预填 `txt`；
  - 点「创建」在当前目录生成 `<名称>.<扩展名>` 空文件后关闭并刷新列表。
- 校验：同名冲突 / 非法字符（`..` `\` `\0` 等）拦截；ROOT 授权优先 `su touch`，无 ROOT 回退 `java.io.File.createNewFile()`。

## 4. 📝 文本编辑器

> 入口：文件页「编辑文本」动作，或从主页 / 选择器打开文本文件。

- **基础能力**：打开 / 编辑 / 保存 / 另存为 / 新建；未保存时标题显示 `●` 并在关闭前提醒；自动保存草稿（间隔秒数可配，0 = 关闭）。
- **大文件分段只读**：超过约 2MB 走 `LazyColumn` 只读分段加载，禁止编辑保存以防数据截断；小文件全量可编辑。
- **行号**：可开关，与编辑区共享滚动状态纵向同步。
- **字号**：8–32sp 可调。
- **编码**：自动检测（BOM → UTF-8 严格校验 → GB18030 中文兜底 → ISO-8859-1），可手动切换 UTF-8 / UTF-16 LE / UTF-16 BE / GBK / GB2312 / GB18030 / ISO-8859-1 / ASCII，保存时按需写 BOM。
- **换行风格**：自动识别并保留 LF / CRLF / CR，保存时按指定风格统一。
- **查找 / 替换**：查找下一个（光标位置环绕查找）、替换当前、全部替换。
- **编辑历史**：每文件最多 20 条（内容级去重，类 git 无变更不入库），可在「历史」中回看。
- **全文统计**：字符数、行数、纯英文数、纯中文数、纯数字数、字节数、最长行；仅在打开设置面板时计算一次（非实时重算）。
- **右侧细滚动条**：贴右缘 6dp 细条，拖动跳行并实时显示目标行号（大小 / 小文件通用）。
- **工具栏**：查找 / 对比 / 历史（带计数）/ 保存 / 设置。

## 5. 🔍 文本对比

入口：编辑器「对比」→ 选择 2 号对比文件（同后缀过滤、排除自身）→ 选择模式 → 执行（带进度与取消）。

- **逐行对比**：按行号一一对应，仅输出**内容相同的行**，格式 `[行号]\t内容`；不相同的全部排除。
- **重复对比**：忽略行号，输出两文件**共同行**（去重，纯文本，按最小行号排序）。
- **大文件优化**：内存映射（mmap）零拷贝读取，ROOT 不可直读文件先 `cat` 到临时文件；10 万行级性能；结果文件命名 `文本对比_YYYYMMDD_n<原扩展名>`。

## 6. 🗜️ 压缩包解压

- **支持 14 种格式**：归档型 `zip / 7z / tar / tgz / tar.gz / tar.xz / tar.zst / tar.bz2 / tar.lz4`；单文件压缩型 `gz / xz / bz2 / zst / lz4`（直接解压为去后缀原文件名）。**RAR 为专有商业格式，不支持**。
- **智能解压**：
  - 条件 A：根目录仅 1 个顶层文件夹 → 直接将其解压到当前目录（剥离顶层前缀，避免 `abc/abc` 嵌套）。
  - 条件 B：否则新建「压缩包名（去后缀）」文件夹容纳全部内容。
- **加密包**：zip（ZipCrypto + WinZip AES，UTF-8 中文密码）与 7z 加密时返回需密码状态，UI 弹窗收集密码后重试。
- **边界处理**：重名冲突自动追加 `_1` `_2`…；剥离 `../` 路径穿越；清理解压失败遗留空目录。

## 7. ⭐ 书签

- 永久存储于 `SharedPreferences`（`bookmarks`，`LinkedHashSet` 保序），跨进程 / 重启存活。
- 弹窗三段式：标题 + 可滚动书签列表（纯文本贴边，点击跳转、✕ 删除）+ 底部「添加书签」（收藏当前目录）。
- 路径归一化（`/` 结尾修剪）与去重；主页与文件页共用同一弹窗与存储。

## 8. 📦 添加到 shso

- 文件页长按文件 → 「添加到 shso」：复制到 `/data/adb/shso` 工作区（ROOT 专属写入）。
- 受三个行为开关控制（设置页）：
  - `独立存储`：存到带时间戳的独立文件夹。
  - `自动删除`：添加后删除原始文件。
  - `自动执行`：添加后跳转终端立即执行。

## 9. 🔧 设置（Settings）

- **权限区**（实时检测，绿 = 已获得 / 红 = 未获得，点击跳系统授权页）：

## 🛠️ 执行引擎与 ROOT 架构

- **执行流程**：`su -c` 启动子进程 → 注入环境变量（`PATH` / `TERM=xterm-256color` / `LANG`）→ 自动 `chmod 777` → 运行 `.sh` / `.so`（`.so` 直接执行，失败回退 `sh`）。
- **I/O 与渲染**：16ms 微批次缓冲队列 → ANSI 着色 + 滑动窗口处理 → Compose 终端流畅呈现。
- **生命周期与信号**：实时捕获运行状态与退出码；支持 stdin 输入、`Ctrl+C`（SIGINT）中断、强制 `kill -9` 结束进程；主页「有任务正在进行中」卡片显示任务名 / 路径 / 已运行秒数。
- **横幅（HyperCore）**：引擎初始化横幅含环境 / 内核 / ROOT 状态；`HyperCore 终端提示` 与 `shso 终端提示` 可独立开关。
- **ROOT 优先级**：`RootFileManager` 以 `preferRoot()` 为 gate——仅当 `RootService.isRootGranted == true` 才走 `su -c`；列表读取 / 路径探测在授权时也优先 ROOT，否则本地回退；`delete/copyFile/rename` 授权即 su 优先、失败或无权再回退 `java.io.File`。

```mermaid
graph LR
    A[选择 .sh / .so 执行目标] --> B[ROOT 探测 & 环境变量注入]
    B --> C[启动 su 子进程 & 挂载 I/O 管道]
    C --> D[16ms 微批次缓冲队列]
    D --> E[ANSI 着色与滑动窗口处理]
    E --> F[Compose 终端界面流畅呈现]
```

## 🚀 快速上手

1. **安装并授权**：安装 shso 后打开，授予「所有文件访问权限」与 ROOT 超级用户权限（ROOT 授权在设置页可随时查看与补授权）。
2. **选择目标**：
   - **方式 A**：在「主页」直接输入文件绝对路径，或点击「从文件管理器选择」；
   - **方式 B**：在「文件」页找到目标脚本 / 程序，长按选择「添加到 shso」；
   - **方式 C**：将脚本直接放置于 `/data/adb/shso/` 目录下。
3. **开始执行**：点击「立即执行」，界面自动切换至「终端」页展示实时运行日志。
4. **控制与交互**：运行中可通过底部输入栏向进程发送输入参数，或使用「中断」/「结束进程」控制任务。

## 🏗️ 源码构建

本项目为**自包含工程**：仅 `include(":app")`，无任何仓库外源码 / 模块依赖，clone 后可直接独立构建。

```bash
# 1. 克隆本仓库
git clone https://github.com/yezijinn/shso.git
cd shso

# 2. 编译 Debug 调试包
./gradlew :app:assembleDebug

# 3. 编译 Release 正式包
./gradlew :app:assembleRelease
```

> Windows 下可运行仓库内一键脚本 `python build_apk.py --skip-check`（内含 V2+V3 签名与产物校验）。

编译输出的 APK 默认位于 `app/build/outputs/apk/` 目录下（Release 产物默认签名为 V2+V3，签名文件 `release.jks` 不在仓库内）；仓库内一键脚本 `python build_apk.py` 已将 `buildDir` 重定向至 `shso-main/.tmp/build_out/app/outputs/apk/` 取包（规避部分环境对 `app/build` 的句柄占用）。

#### ❓ 常见问题（FAQ）

**Q：包名填错了被拒绝（红色叉）怎么办？**
A：回到 Actions → 点「在线编译 APK（自定义包名）」→ 再点 Run workflow → 换个合规的包名重新提交即可。失败日志最后一行会写明原因（例如「禁止使用作者原包名」）。

**Q：编译失败了（红色叉）但包名没问题？**
A：GitHub 偶尔会抽风，直接重新点一次 Run workflow 再跑一遍通常就好。若反复失败，点进任务详情页看日志最后几行的报错信息。

**Q：我找不到 Actions 标签 / 没有 Run workflow 按钮？**
A：确认你在**自己 fork 的仓库**（网址是 `github.com/你的用户名/shso`），不是作者的仓库。第一次进 Actions 需点绿色「I understand...」确认按钮。

**Q：下载到的是 zip 不是 apk？**
A：正常！GitHub 导出的就是 zip 压缩包，解压后里面的 `app-release.apk` 才是安装文件。

**Q：怎么确认装上的 APP 包名真的是我填的那个？**
A：手机「设置 → 应用管理」找到 shso，应用信息里会显示包名；或在电脑用命令 `aapt dump badging app-release.apk` 查看 `package: name=...`。我们已实测验证：填 `com.verify.demo` 导出的 APK，内部包名确实是 `com.verify.demo`。

#### 🔧 原理说明（进阶，看不懂可跳过）

> 编译仅覆盖 `applicationId`（安装身份），`namespace` 与源码包名保持 `com.mixradio.droid` 不变，因此 `R` / `BuildConfig` 与全部 `import` 不受影响；FileProvider authority、跳设置页 Uri 等均基于 `${applicationId}` / `context.packageName` 自动跟随。CI 环境自动改用调试密钥签名，导出的 APK 可直接安装。

## 🛡️ 安全与防护说明

- **防 Shell 命令注入**：所有通过 `su -c` 调用的路径均采用标准单引号转义处理（`replace("'", "'\\''")`）。
- **防路径穿越**：文件管理与重命名严格过滤 `..`、`\`、`\0` 等异常路径字符。
- **授权超时熔断**：ROOT 鉴权检测加入协程超时限制（约 1.5s），避免因授权管理器卡死导致应用未响应。
- **滑动窗口防 OOM**：终端输出上限 25 万字符自动截断。
- **安全数据保护**：关闭 `allowBackup`，防止通过 ADB 备份机制提取私有数据。

### 🔄 版本号规则与检查更新

- **版本号 = 构建当日日期**：每次编译 APK 时，`versionCode` 自动取当天日期的纯数字（`YYYYMMDD`，例如 `20260905`），同时作为「是否有新版」的唯一判定依据；GitHub 发布标签也强制采用**纯日期**格式（如 `20260905`），二者天然对齐。
- **检查更新（设置页）**：设置页底部「检查 github 是否发布了新的版本」一项，点击后应用会抓取 `https://github.com/yezijinn/shso/tags`，正则提取其中的纯数字标签（兼容 `v20260904` 与 `20260904` 两种写法），取最大值与本地 `versionCode` 做大小比较：
  - 远端更新 → 显示「发现新版本：\<tag\>」+「去更新」按钮（跳转 `https://github.com/yezijinn/shso/releases`）；
  - 已是最新 → 显示「已是最新版本 无需更新」；
  - 网络异常 → 弹框提示「网络不佳 建议开启科学上网」。
- **作者发布纯日期版本**：仓库 `Actions` 中另提供「发布 Release（纯日期标签）」工作流（手动触发），自动以当日日期打标签并上传 APK；留空则取构建当日，亦可在表单中手动指定 `YYYYMMDD` 标签。
