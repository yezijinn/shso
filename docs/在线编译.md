# 在线编译 APK（自定义包名）

不需要 Android Studio 与 Java / Android SDK，只要一个 GitHub 账号，
在网页上即可生成自定义包名的 APK：Fork 本仓库 → `Actions` →
「在线编译 APK（自定义包名）」→ `Run workflow` → 填包名 → 下载产物。

入口与摘要见 [`README.md`](../README.md) § 构建。

## 准备

- GitHub 账号（免费）。
- 一台可上网的电脑或手机（建议用电脑）。

## 步骤

1. 打开 <https://github.com/yezijinn/shso>。
2. 点右上角 **Fork** → **Create fork**，项目复制到自己的账号下
   （网址变为 `github.com/<用户名>/shso`）。后续操作都在自己的仓库进行。
3. 进入自己仓库的 **Actions** 标签；首次进入需点
   「I understand my workflows, go ahead and enable them」确认。
4. 左侧工作流列表选择 **「在线编译 APK（自定义包名）」**。
5. 点右侧 **Run workflow** 展开表单。
6. 在 `package_name` 输入框填写包名。
   - 合规：全部小写字母；以 `.` 分成至少两段；每段以字母开头。
     例如 `com.zhangsan.shso`、`com.myname.myapp`。
   - 拒绝：`com.mixradio.droid` 及任何 `com.mixradio.*`；
     含大写、中文、空格的名称。
7. 点表单下方绿色 **Run workflow** 开始编译。
8. 等待任务结束：黄点运行中，绿色对勾成功，红色叉失败。通常 4～10 分钟，
   首次较慢（需下载编译工具）。可点进任务查看实时日志。
9. 成功后在任务详情页底部的 **Artifacts** 下载压缩包，
   名称形如 `app-release-com.<你填的包名>`。产物默认保留 30 天。
10. 解压得到 `app-release.apk`，传到手机安装
    （首次安装需允许「安装未知来源应用」）。

## 常见问题

**包名填错被拒绝？**
重新 `Run workflow` 并更换合规包名；失败日志最后一行会写明原因。

**包名没问题但编译失败？**
重试一次通常即可；反复失败时查看任务日志末尾的报错。

**找不到 Actions 标签或 Run workflow 按钮？**
确认在自己 fork 的仓库（网址为 `github.com/<用户名>/shso`）；
首次进入 Actions 需点确认按钮。

**下载的是 zip 不是 apk？**
正常。GitHub 导出为 zip，解压后的 `app-release.apk` 才是安装文件。

**如何确认包名已生效？**
手机「设置 → 应用管理」查看应用信息，或执行
`aapt dump badging app-release.apk` 查看 `package: name=...`。

## 原理

编译只覆盖 `applicationId`（安装身份），`namespace` 与源码包名保持
`com.mixradio.droid` 不变，因此 `R` / `BuildConfig` 与全部 `import` 不受影响；
FileProvider authority、跳设置页 Uri 均基于 `${applicationId}` /
`context.packageName` 自动跟随。CI 使用调试密钥签名，产物可直接安装。
