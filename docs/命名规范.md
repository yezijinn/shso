# 命名规范

Kotlin 与 Compose 代码的命名约定。与 Kotlin 官方编码规范一致的部分不再解释原因，本文件只列出本工程的强制项与豁免项。

- 相关：[`docs/PROJECT.md`](PROJECT.md)（架构与约束）、[`docs/文档规范.md`](文档规范.md)（文档写作准则）。

## 通用规则

| 元素 | 风格 | 示例 |
|---|---|---|
| 包 | 全小写，无下划线 | `com.mixradio.droid.data.security` |
| 类 / 接口 / 对象 / 注解 | PascalCase | `RootService`、`ScriptAuditor` |
| 枚举条目 | UPPER_SNAKE | `RiskLevel.CRITICAL` |
| 函数 / 属性 / 局部变量 | camelCase，动词开头 | `listFiles`、`resolveTargetPath` |
| `const val` 与顶层不可变集合 | UPPER_SNAKE | `MAX_LOG_LENGTH`、`TEXT_EXTENSIONS` |
| 主题设计令牌 | PascalCase（例外，见下） | `AuroraTokens`、`AuroraShapes` |
| 类型参数 | 单个大写字母 | `T`、`R` |
| 测试函数 | 反引号 + 中文陈述句 | `` fun `档位 0 与 1 不注入守卫 PATH`() `` |

**主题令牌例外**：`Aurora*` 系列为设计令牌对象（颜色 / 形状 / 字体 / 文本样式），按对象而非常量命名，故用 PascalCase。新增令牌沿用该前缀，不要改成 UPPER_SNAKE。

## Compose 约定

- 无返回值的 `@Composable` 函数用 **PascalCase 名词**：`DockBar`、`SettingsPage`。
- 带返回值或返回 `Modifier` 的用 camelCase：`auroraGlass(...)`、`auroraFilledButton()`。
- 状态提升参数用 `value` / `onXxxChange` 命名；事件回调用 `onXxx`，不用 `xxxListener` / `onXxxClick` 混写。
- 预览函数以 `Preview` 结尾。

## 布尔与常量

- 布尔用 `is` / `has` / `can` / `should` / `use` / `show` / `auto` 前缀，禁止裸 `flag`、`enabled` 单用（应有主体，如 `guardInstalled`）。
- 时间量必须带单位后缀：毫秒 `*Ms`（禁止 `ms` / `Ms` 混用），秒 `*Sec`，纳秒 `*Nanos`。
- 阈值常量命名要体现含义：`LARGE_FILE_THRESHOLD`，不要写 `LIMIT` / `MAX_SIZE` 这类无上下文的名字。
- 单位写在名字里：`backlogChars`、`minIntervalMs`。

## 项目词汇表

同一概念全文只用一种叫法，已发生歧义的以本表为准：

| 概念 | 命名 | 禁用 |
|---|---|---|
| 是否以 ROOT 执行 | `runAsRoot`（跨层参数）/ `useRoot`（局部开关） | `root`、`isRooted`、`asRoot` |
| 横幅开关 | `showHyperCoreBanner` / `showShsoBanner` | `showBanner`、`showHyperCore` |
| 安全档位 | `level` / `securityLevel` | `tier`、`grade` |
| 风险等级 | `RiskLevel` / `level` | `severity`、`risk` |
| 路径 | `path`（文件绝对路径）、`dirPath`（目录）、`name`（文件名） | `filePath` 与 `path` 混用 |
| 守卫模块 | 模块 id 固定 `shso_guard`；Kotlin 侧用 `Guard*` | `guardian`、`sentinel` |
| 品牌 | 包名与文案用 `shso`；类名前缀 `Shso` | `KernelEX`（历史名，仅旧设备目录保留） |

## 禁止项

- 标识符一律不用下划线（测试函数名与 `const val` 除外）。
- 缩写词统一大小写：写 `Apk` / `apk`，禁止 `APk` / `aPK`；已定型缩写（ANSI / SELinux / OBB）按既有写法。
- 不用匈牙利前缀（`mPath`、`strName`）。
- 业务语义变量禁止单字母：字符循环用 `ch`，文件用 `file`，结果用 `result`，路径用 `path`。允许豁免：`i` / `j` 索引、lambda 的 `it`、坐标 `x` / `y` / `w` / `h`、时间分量 `h` / `m` / `s`、长度 `n`。
